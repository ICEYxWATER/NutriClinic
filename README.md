# AyuDiet Connect

Interactive SIH25024 prototype for Ayurvedic diet planning.

Open `index.html` in a browser. Select an illustrated food, add a portion, and drag the 3D bowl to rotate it. The app also supports patient profiles, nutrition totals, meal plan approval, PDF printing, and follow-up notes.

The prototype works offline and stores records in your browser. Use fictional patient details and treat the food catalog as demo data.
